Ads Lighthouse provides brand search ad monitoring for Google and Bing, offering tools for advertisers, agencies, and affiliates to track brand appearances, compliance, and competition. The platform includes integrations with Slack, webhooks, email, and Google connections, delivering real‑time alerts, reports, and templates to help users manage paid‑search campaigns effectively.

**Areas:** Company · Advertising · Monitoring · Brand Protection

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Ads Lighthouse: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
